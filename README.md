TASK 2 – STOCK TRADING PLATFORM USING JAVA
1. Introduction

The Stock Trading Platform is a Java-based application developed as part of my CodeAlpha Java Programming Internship.

The main purpose of this project is to create a simple stock trading simulation system that allows users to view available stocks, check stock prices, buy stocks, and sell stocks.

Stock trading is an important part of the financial market. This project provides a basic understanding of how stock trading operations work through a simple Java application.

The application simulates stock transactions and helps users understand the basic concepts of buying, selling, and managing stocks.

2. Project Objective

The main objective of this project is to develop a simple stock trading platform using Java programming.

The objectives include:

To display available stocks.
To show stock names and prices.
To allow users to buy stocks.
To allow users to sell owned stocks.
To maintain the user's account balance.
To calculate transaction amounts.
To display portfolio information.
To understand basic financial transaction concepts.
To improve Java programming and problem-solving skills.
3. Project Description

The Stock Trading Platform is a console-based application developed using Java.

The application allows users to interact with a simulated stock market. Users can view the list of available stocks along with their prices.

Users can buy stocks by entering the stock name and quantity. The application checks whether the user has sufficient balance before completing a purchase.

Similarly, users can sell stocks that they already own. The platform updates the account balance and portfolio after every successful transaction.

This project demonstrates how Java can be used to develop simple financial management and trading applications.

4. Features of the Project
1. View Available Stocks

Displays the list of available stocks along with their names and prices.

2. Buy Stocks

Allows users to purchase stocks by entering the stock name and required quantity.

3. Sell Stocks

Allows users to sell stocks available in their portfolio.

4. Account Balance

Maintains and displays the user's available account balance.

5. Portfolio Management

Displays the stocks owned by the user and their respective quantities.

6. Transaction Management

Updates the account balance and stock quantity after successful transactions.

7. Input Validation

Checks user inputs and prevents invalid transactions.

8. User-Friendly Interface

Provides a simple menu-driven interface for easy interaction.
